ferspas-tile

XYZ tiles with a time axis, read on the fly from FAO FERSPAS Cloud Optimized GeoTIFFs. Nothing is pre-built; a tile is computed when it is asked for.

Tile URLs carry the instant as well as the tile index: /analysis/{id}/{time}/{z}/{x}/{y}.png

Analyses

Each one is a file in functions/ named after its id. They combine collections the upstream API does not combine.

Raw collections

The values as FERSPAS publishes them, drawn with FAO's own colour ramp for that collection. Longest time series first; the full list is here.
